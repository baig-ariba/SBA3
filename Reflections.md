# Reflections

The main challenges were creating the background image, the more 3 dots and the cutout in the contact section and getting the screen and descrription in the middle of the page.

I was planning on doing a vanilla CSS first and then finding the corresponding Tailwind or BootStrap properties and switching them but once a low-level fidelity diagram for the webpage was done it became easy to work out the styling within the html using Tailwind. I started off with tailwind because the utilities there were more defined and more elaborate than BootStrap. I tried to do each section one at a time to figure out how the things worked and once completed the next one was added on. The media queries are added in the CSS file because I am still trying to figureout the sm, md and lg.
