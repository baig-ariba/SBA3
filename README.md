# Chat App Css illustration -Frontend Mentor Challenge

## Oveview

The chat project is an illustration of an app which is for dog-walking. The chat allows the dogwalker to discuss arrangements and bookings with a potential client. It allows the dog-walker to share thier fees according to the mins set. The app also allows the sharing of images between the two. The webpage also gives a small overview of what the booking system doeslike make arrangements or bookings.

## Approach and Customizations

I made a sketch of the web design and then divided it up into boxes. I made 4 separate sections for each sectiuon so it got easier to work through them. One div was for the background, one for the entire screen, one for the webpage description and the last one for the footer. And then in each div flexboxes and more divs to make it easier. 
I had to customize the background since it was not provided in the assets. The 3 dots in a column on the contact area were also customized while the submit button also needed a cutomized arrow. The cutout for the mobile was also customized.

## Challenges

The main challenge were the customization of the images needed. Other than that it was trying out differnt styling option.
